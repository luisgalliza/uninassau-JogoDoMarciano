# 👽 Jogo do Marciano — Java | UNINASSAU 🇧🇷

Este repositório contém o **Jogo do Marciano**, desenvolvido em **Java** como parte de uma **atividade acadêmica avaliativa da UNINASSAU**, com o objetivo de colocar em prática conceitos fundamentais de programação e lógica computacional.

## 📌 Objetivo

O objetivo da atividade foi desenvolver um **jogo de adivinhação** no qual um marciano se esconde aleatoriamente em uma das **100 árvores disponíveis**.

O jogador deve tentar descobrir em qual árvore o marciano está escondido. A cada tentativa, o programa fornece uma dica indicando se o número correto é **maior ou menor** que o valor informado.

A atividade permitiu praticar conceitos como:

- Lógica de programação;
- Estruturas condicionais;
- Estruturas de repetição;
- Geração de números aleatórios;
- Entrada e saída de dados;
- Variáveis e operadores;
- Contagem de tentativas.

## 🎮 Funcionamento do Jogo

Ao iniciar o programa:

1. O marciano é posicionado aleatoriamente em uma árvore entre **1 e 100**;
2. O jogador informa o número da árvore em que acredita que o marciano está;
3. O programa indica se o marciano está em uma árvore de número **maior ou menor**;
4. As tentativas continuam até que o jogador encontre a árvore correta;
5. Ao final, o programa informa o acerto e a quantidade de tentativas realizadas.

## 🛠️ Tecnologias Utilizadas

- **Java**
- **Visual Studio Code**
- `Scanner` — entrada de dados;
- `Random` — geração da posição aleatória do marciano.

## 🎓 Contexto Acadêmico

Projeto desenvolvido como **atividade avaliativa do curso de Ciência da Computação da UNINASSAU**, com foco na aplicação prática dos fundamentos da linguagem **Java**.

A atividade contribuiu para o desenvolvimento da lógica de programação, compreensão do fluxo de execução e utilização de estruturas fundamentais da linguagem.

# 👽 Martian Game — Java | UNINASSAU 🇺🇸

This repository contains the **Martian Game**, developed in **Java** as part of a **graded academic assignment at UNINASSAU**.

The project was created to practice fundamental programming concepts through a simple guessing game.

## 📌 Objective

The goal of the game is to discover where a Martian is hiding among **100 numbered trees**.

The Martian's position is randomly generated, and the player must enter guesses until finding the correct tree.

After each attempt, the program provides a hint indicating whether the correct number is **higher or lower** than the player's guess.

This project helped practice concepts such as:

- Programming logic;
- Conditional statements;
- Loops;
- Random number generation;
- User input and output;
- Variables and operators;
- Attempt counting.

## 🎮 How the Game Works

When the program starts:

1. The Martian is randomly placed in a tree between **1 and 100**;
2. The player enters the number of the tree where they think the Martian is hiding;
3. The program indicates whether the correct number is **higher or lower**;
4. The game continues until the player finds the correct tree;
5. At the end, the program displays the successful guess and the total number of attempts.

## 🛠️ Technologies Used

- **Java**
- **Visual Studio Code**
- `Scanner` — user input;
- `Random` — random Martian position generation.

## 🎓 Academic Context

This project was developed as a **graded academic assignment for the Computer Science program at UNINASSAU**, focusing on the practical application of fundamental **Java programming** concepts.

The activity helped strengthen programming logic, control flow understanding, and the use of essential Java structures.
